## Provisional Findings

### INTENT-PROV-0040 — 상수 전이 엔트로피도 겹침 가중으로 부호 교차를 만든다

`REVIEW_F1.md`, `REVIEW_CH2_C2F3.md:18-28`,
`TRIAGE_P7.md:18`은 Ch2 서두의
“전이마다 상수인 \(\Delta S_{\mathrm{rxn},j}\)로는 부호 반전 자유도가
없다”는 문장을 과일반화로 판정했다.

서로 다른 부호의 전이 중심값을 봉우리 가중 평균하면 조성 축의
부호 교차는 가능하다. 상수 중심값만으로 만들 수 없는 것은 한 전이
내의 구성 엔트로피 발산형 경계 구조, 입력 중심값의 볼록껍질 밖
극값, 그리고 그와 연동된 날카로운 봉우리·골이다.

판정:

- 정정 자체는 `PRESERVE`.
- 최종 문건은 “부호 변화”와 “국소 구조·발산·곡률 생성”을 분리해
  서술해야 한다.
- 더 복잡한 엔트로피 항의 필요성을 과장된 불가능성 주장으로
  정당화하지 않는다.

### INTENT-PROV-0041 — 입자당·몰당 에너지 층위를 식마다 봉인해야 한다

`REVIEW_O1.md`은 \(\beta=1/k_BT\)와 짝을 이루는
\(\mu_{\mathrm{Li}}\)를 “몰 표기”라고 부른 신설 문장이
같은 문건의 세 위치에 있는 입자당 규약과 충돌한다고 지적했다.
`TRIAGE_P7.md:9`는 이를 “자리당 표기”로 정정했다.

이는 문구 하나의 문제가 아니다. 문건에는
\(k_B,T,\varepsilon,\mu\)의 입자당 층과
\(R,T,\Delta H,\Delta S,FU\)의 몰당 층이 모두 존재한다.
두 층의 변환 \(N_A k_B=R\), \(N_A e=F\)가 생략되면
차원은 그럴듯해 보여도 물리 해석이 바뀔 수 있다.

판정: `PRESERVE` 및 최종 감사의 하드 게이트.
모든 핵심 식은 에너지 기준을 명시하고,
입자당↔몰당 변환은 기호 정의 또는 유도 중간식에서 추적 가능해야 한다.

### INTENT-PROV-0042 — 폭의 이중 지위와 온도 법칙은 아직 실험으로 닫히지 않았다

`REVIEW_O2.md`와 `TRIAGE_P7.md:13`은 \(w_j\)가
내재 평형 폭과 여러 broadening이 합쳐진 총 유효 폭으로
겹쳐 쓰이는 문제를 지적했고, P7은 폴백 폭을
“②·③을 분리하지 않은 유효 폭”으로 보강했다.

그러나 여섯 Ch2 review가 공통으로 가장 약한 지점으로 고른 것은
더 근본적이다. 계산 예제의 config 몫과 일부 흡·발열 부호는
두-상 전이에서도 \(w_j=n_jRT/F\)로 스케일한다는 전제에 의존한다.
문건은 이 전제를 미검증으로 공개하고 단순식을 보수 기준으로
제시했지만, `CODE_IMPL_REPORT.md:77-121`의 수치 gate는 같은 전제를
구현한 모델 안의 자기일관성만 검증한다.

판정:

- 폭의 출처 분해와 기호 지위 정리는 `CORRECT`.
- 두-상 폭의 \(T\) 법칙은 `UNVERIFIED`.
- 다온도 실제 데이터 round-trip 전에는
  \(-0.204\ \mathrm{mV\,K^{-1}}\) 같은 값과
  \(\bar{x}=0.75\)의 열 부호를 재료 보편값으로 승격하지 않는다.

### INTENT-PROV-0043 — 인용은 존재 여부가 아니라 주장 범위를 검증해야 한다

`REVIEW_O3.md`와 `TRIAGE_P7.md:15`는 `ml2024`가
order–disorder/configurational 계산의 근거이지
MIT 전자 엔트로피의 tier-A 근거가 아님을 확인했다.
P7은 해당 인용을 config 전용 예시로 축소했다.

같은 review는 불순물-Mott 미시기작과
config⊥electronic 가산 가정 사이의 연결도
별도 가드가 필요하다고 판정했다.
Ch2 review들은 K-intercalated graphite 문헌을
Li graphite의 직접 근거가 아니라 유사성 근거로 읽어야 한다는 점,
내부자료 `numverif2026`가 실측 검증을 대체하지 못한다는 점을 반복했다.

판정:

- 서지 필드 검증과 주장-문헌 scope 검증을 분리한다.
- review 논문·유사 재료·내부 검증은 load-bearing 1차 실험 근거와
  같은 증거 등급으로 쓰지 않는다.
- 최종 문헌 조사에서는 원전의 실제 문장·그림·조건을 다시 대조한다.

### INTENT-PROV-0044 — 다중 검토의 합의는 내부 정합성 증거이지 실험 권위가 아니다

P7은 독립 검토 11본의 union을 만들고,
두 창 이상 공통 지적 또는 master의 재유도 확인을 거쳐
18개 처분을 채택했다. 이 방식은 단위, 표기, 인용 scope,
재현 규약, 과일반화 같은 결함을 찾는 데 유효했다.

동시에 `RESULT_P7_review.md`의 H=0, build green,
식 블록 hash 불변, 다수 창 완주라는 기록은
v1.0.20의 실험 적합성을 뜻하지 않는다.
review 자체가 공통 최약점으로
“두-상 폭의 다온도 실데이터 round-trip 미완료”를 남겼다.

판정:

- union/refute/재유도 절차는 `PRESERVE`.
- 검토자 수, 모델 이름, 다수결, 빌드 성공은 과학 권위로 사용하지 않는다.
- 최종 gate는 문헌·차원·극한·독립 수치·실제 데이터 판별력을
  각각 별도 통과해야 한다.

### INTENT-PROV-0045 — v1.0.20 코드는 새 물리 구현판이 아니라 v1.0.19 정합 이월판이다

변경이 버전 문자열과 문건 포인터뿐이라고 명시한다.
G1/G2/G3는 하위호환, 문건 회귀값, Einstein 보정 및 \(n(T)\) 전파를
재현했지만 실제 흑연·LCO·Si 데이터에 대한 신규 적합은 수행하지 않았다.

판정:

- v1.0.20의 코드는 “문건 계약과 일치하는 v1.0.19 계승 구현”으로
  계보에 기록한다.
- “v1.0.20 코드 gate PASS”를
  “재료 물리 검증 완료”로 번역하는 것은 `REJECT`.
- 코드 완결성 판정은 이후 전 버전 코드 계보와 실제 데이터 검증에서
  다시 수행한다.

### INTENT-PROV-0046 — 방향성 보고서는 채택된 이론이 아니라 v1.0.21 후보 목록이다

`DIRECTION_STATMECH_REPORT.md`와 `DIRECTION_GENERAL_REPORT.md`는
명시적으로 읽기 전용 제안서이며 사용자 GO 전에는 실집행하지 않는다고
선언한다. 우선 후보는 다음과 같다.

- 다클래스 대정준 전하 보존 반전과
  \(dQ/dV\)의 요동–응답/감수율 해석.
- Eyring TST의 \(k_BT/h\)와
  \(\Delta S_a=R\ln(q^\ddagger/q_R)\) 유도.
- 기존 CNT 부록과 과주행·\(\gamma_j\)의 연결.
- Ch1 end-to-end worked example, Ch1↔Ch2 항법 표,
  측정 원리 배경, 흑연↔LCO 대조표.

반면 CLT broadening은 forward-only 등 네 가드가 필요하고,
단상 \(w_{\mathrm{eff}}(\Omega)\) 식의 재도입은
두-상 금지식과 시각적으로 같아 고위험,
staging 상관함수와 비평형 요동정리는 범위 밖 후보로 분류됐다.

판정:

- 위 목록은 `THEORY_ONLY` 후보이며 자동 승계하지 않는다.
- 이후 v1.0.21–v1.0.25.2에서 사용자가 실제로 승인하고
  문헌·유도·데이터 gate를 통과한 항목만 계보상의 채택 결정으로 인정한다.
- v1.0.20 방향 보고를 근거로 후대 구현을 소급 정당화하지 않는다.

### INTENT-PROV-0047 — 사용자가 원한 “교재+리뷰+피팅”의 결합 구조가 드러난다

두 방향 보고서가 포착한 사용자의 요구는 단순한 식 추가가 아니다.

1. 통계역학은 초반 배경으로 끝나지 않고
   전하 보존, \(dQ/dV\), 동역학 장벽, broadening,
   상전이 과주행까지 논리적으로 관통해야 한다.
2. 긴 문건은 실제 계산을 끝까지 따라가는 worked example,
   절·챕터 대응 지도, 재료 간 “같은 것/바뀌는 것” 표로
   대학원 교재처럼 항해 가능해야 한다.
3. 이론량 \(U_{\mathrm{oc}}\), \(\partial U/\partial T\),
   가역열은 GITT/휴지 전위, 전위차 엔트로피 측정,
   calorimetry 같은 실험 관측과 연결되어야 한다.
4. 측정 배경은 물리 이론과 실험 대응까지만 다루고,
   이론 본문을 코드 설명이나 실험 매뉴얼로 바꾸지 않는다.
5. 코드 명칭·함수·회귀 계약은 지정 부록 또는 외부 구현 문건에만 두며,
   이론 본문은 물리·화학 논리만으로 자립한다.

판정: `USER_REQUIREMENT`, `PRESERVE`.
다만 과거 방향 보고서가 제안한 “코드맵 부록”도
사용자의 최신 제약에 맞춰 이론 본문과 물리 구현 계약을 분리해 재배치한다.

### INTENT-PROV-0048 — 후속 작업의 우선순위는 설명 증설보다 실험 폐쇄다

P7 기록만 놓고 보면 가장 가치가 큰 후속 이론 연결은
대정준 전하 보존/요동–응답, Eyring TST, CNT 과주행이다.
그러나 이들도 공개 데이터 설명을 대신하지 못한다.

최종 작업의 우선순위는 다음 순서를 따라야 한다.

1. 실제 저율·휴지·다온도·rate·interruption 데이터로
   평형 중심, 분극, broadening, lag, memory를 분리.
2. 흑연, Si, 흑연+Si, 도핑 고전압 LCO 각각에서
   어떤 이론 항이 관측으로 식별되는지 판정.
3. 식별되지 않는 항은 문헌 배경으로 남기고 기본 피팅 자유도로 올리지 않음.
4. 살아남은 물리만 문건의 정식 유도와 코드의 1:1 계약으로 연결.

판정: `PRESERVE`.
“설명이 더 깊다”와 “데이터를 더 잘 설명한다”를 별도 gate로 둔다.
