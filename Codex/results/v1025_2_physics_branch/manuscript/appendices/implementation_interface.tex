\section{구현 인터페이스와 물리 계약}\label{ASM-IMPLEMENTATION}

이 부록만 실제 구현 기호를 언급한다. 물리 본문은 이 기호들에
의존하지 않으며, 실제 경로와 세부 추적 정보는 원고
밖의 추적 기록에 둔다.

\subsection{권장 경계}

\paragraph{\physid{ASM-IMP-01} 물리 host 계약.}
\texttt{PhysicalHostBlend}는 동일한 $V_n$, $T$, signed 전하 basis에서
$Q_\mathrm{Gr}$와 $Q_\mathrm{Si}$ 및 필요 상태미분을 제공하고
식~(8.1)의 balance를 푼다. 경험 peak 배열을 입력으로 요구하지 않는다.

\paragraph{\physid{ASM-IMP-02} 경험 관측 계약.}
\texttt{EmpiricalSkewProfile}은
$\{U_j,w_j,A_j^\obs,\alpha_j,B_\obs\}$, 관측창, 단위,
전처리 식별지문을 소유한다. physical host, reaction entropy,
rate constant와 heat source를 노출하지 않는다.

\paragraph{\physid{ASM-IMP-03} 호환 경계.}
\texttt{LegacyCompatibleProfile}은 과거 수치 재현이 필요한 경우에만
관측층 바깥 경계에 둔다. 이것의 결과를 새 물리 기본값으로
승격하지 않고, 선택 사실과 부호ㆍ정상화 규약을 명시한다.

\subsection{필수 불변조건}

\begin{enumerate}[label=\textsf{I\arabic*.},leftmargin=3.2em]
\item 모든 physical transition에 $0\le\xi_j\le1$과 고정 $z_j>0$를
보장한다.
\item equilibrium에서 $J_j^+=J_j^-$이고
$\mathcal A_j^\chem=0$이어야 한다.
\item 전하수지 잔차의 단위는 C이며 선언한 허용오차 안에서 0이다.
\item 시간률의 내부 단위는 s$^{-1}$이고 h$^{-1}$ 입력은 경계에서만
변환한다.
\item empirical skew 성분의 전 실수축 면적은 $A_j^\obs$이고
physical signed coefficient $a_j$와 자료형ㆍ이름을 공유하지 않는다.
\item $I\to0$, $\tau\to0$, host fraction의 끝점과 온도고정 극한이
Appendix~\ref{ASM-CHECKS}의 관계로 환원된다.
\item 전역 mutable switch 없이 같은 상태ㆍ입력은 같은 물리
계약을 선택한다.
\end{enumerate}

\begin{openitem}
\physid{ASM-IMP-OPEN-01}
구현 변경의 승인에는 symbol-level 대응뿐 아니라 단위, 부호,
초기ㆍ경계조건, 제한극한과 식별성 경계의 동시 검토가 필요하다.
경로별 차이와 실행 근거는 외부 conformance 기록에서 관리한다.
\end{openitem}
