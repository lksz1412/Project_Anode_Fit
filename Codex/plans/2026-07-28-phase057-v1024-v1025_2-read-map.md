## Batch Gate

1. queue의 representative path, blob SHA, line count를 대조한다.
2. 첫 행부터 마지막 행까지 읽고 EOF를 확인한다.
3. plan, 경쟁초안, 채택안, 구현결과, user feedback, handover의
   주장 시점을 분리한다.
4. `PASS`, `완결`, `무근거 0`, `bit-exact`, `실측` 주장을
   실제 증거 범위와 대조한다.
5. 각 batch JSON을 coverage applier에 두 번 적용해
   idempotence를 확인한다.
6. 결과·원장·handover를 batch마다 커밋·푸시한다.
