## Batch Gate

각 batch는 다음 순서를 따른다.

1. 경로와 physical line count를 read coverage와 대조한다.
2. 긴 문건은 최대 400행의 연속 구간으로 분할한다.
3. 첫 행부터 마지막 행까지 누락 없이 읽는다.
4. 출력 truncation이 있으면 해당 구간을 더 작게 다시 읽는다.
5. 사용자 확정 지시, Fable/Claude 초안, 경쟁 리뷰,
   마스터 채택, 기계 snapshot을 구분한다.
6. 주장마다 source actor, 근거, 적용 범위와 후속 철회 여부를 기록한다.
7. 구조/build/코드 gate와 물리·문헌·실험 검증을 분리한다.
8. batch JSON을 coverage applier에 적용한다.
9. JSON·행 수·idempotence·diff를 검증하고 커밋·푸시한다.

## 핵심 판독 질문

1. 활물질별 재편이 물리 책임을 명료하게 했는가, 문단 이동에 그쳤는가.
2. v1.0.21의 임시 항법판이 실제로 제거되고 기능이 어디로 흡수됐는가.
3. 통계역학 증축에서 무엇이 채택되고 무엇이 사후 제거됐는가.
4. LCO tier, 온도 복원, charge-order, 비가역열 공백이 해결됐는가.
5. Si/SiO_x/Si–C/blend에 독립 물리식과 실험 근거가 생겼는가.
6. 경쟁 리뷰가 발견한 결함과 마스터가 실제 반영한 수정은 무엇인가.
7. 문건의 코드 언급이 허용 구역을 넘었는가.
8. 코드가 새 문건 식을 실제 구현했는가, `matched` 자기선언에 그쳤는가.
9. 심층 review가 과학적 적대 검산인지 문서 품질 검수인지.
10. v1.0.23으로 이월된 미해결 항목과 실제 정본 방향은 무엇인가.
