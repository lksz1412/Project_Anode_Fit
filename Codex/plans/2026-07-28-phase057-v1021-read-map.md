## Batch Gate

각 batch는 다음 순서로 닫는다.

1. 경로와 physical line count를 read coverage와 대조한다.
2. 긴 JSON은 최대 400행의 연속 구간으로 나눈다.
3. 첫 행부터 마지막 행까지 누락 없이 읽는다.
4. 출력 truncation이 있으면 해당 범위를 더 작게 다시 읽는다.
5. 사용자 확정 지시, 작업자 주장, 기계 snapshot을 구분한다.
6. snapshot 간 label/식 hash/asset/bibliography 차이를 계산하고,
   행 번호 이동과 실제 내용 변경을 분리한다.
7. claim ID와 근거 한계를 result에 기록한다.
8. batch JSON을 coverage applier에 적용한다.
9. 행 수·JSON·idempotence·diff를 검증하고 커밋·푸시한다.

## 핵심 판독 질문

1. v1.0.20에서 제안된 Q2/Q3/LCO/Si 항목 중 무엇이 실제 채택됐는가.
2. 채택된 항목은 본문 물리 논리인가, 참고문헌·내비게이션 보강인가.
3. 코드 언급이 허용 구역을 넘어 이론 본문에 침투했는가.
4. 새 식이 관측량, 상태변수, 온도·전류·전위 의존 장벽을
   더 명확히 했는가, 아니면 설명상 정리만 했는가.
5. snapshot/build/test 주장이 과학적 검증으로 과대해석됐는가.
6. 후속 v1.0.22 이상에서 보존·정정·폐기된 결정은 무엇인가.
