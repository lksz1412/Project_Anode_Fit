## Batch Gate

각 batch는 다음 순서를 따른다.

1. 경로와 physical line count를 read queue와 대조한다.
2. 긴 문건은 최대 400행의 연속 구간으로 분할한다.
3. 첫 행부터 마지막 행까지 누락 없이 읽는다.
4. 출력 truncation이 있으면 잘린 범위를 더 작은 구간으로 다시 읽는다.
5. 직접 지시와 작업자/리뷰어 주장을 분리한다.
6. claim ID, 출처 행, 잠정 판정과 후속 충돌을 result에 기록한다.
7. batch JSON을 coverage applier에 적용한다.
8. JSON, 행 수, diff를 검증하고 커밋·푸시한다.

## Snapshot 판독 규칙

snapshot JSON은 단순히 “기계 생성”으로 치환하지 않는다.
각 파일을 전문 검독하되 다음을 별도로 기록한다.

- label/reference/title 및 구조 변화.
- 코드 토큰 또는 금지어 검출 수치.
- 이전 snapshot과 달라진 값.
- snapshot이 증명할 수 있는 것과 증명할 수 없는 것.

동일한 label 목록의 반복도 실제 행 coverage에는 포함하지만,
그 반복 자체를 과학적 검증 증거로 승격하지 않는다.
