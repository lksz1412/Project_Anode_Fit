## A2. `p-ocvhold` 권고 — 잔여 불일치의 상당분은 모델 결함이 아니라 **데이터의 비평형 잔여**

**[사실]** 같은 7-전이 모델·같은 추출로 **흑연**을 프로토콜만 바꿔 피팅:

| 프로토콜 | R² | 피크 구역 RMSE |
|---|--:|--:|
| `p-ocv` | 0.9770 | 4.708 |
| `p-ocvhold` | **0.9945** | **2.701** |

**[근거]** 마스터 세션 측정(2026-07-26). 모델·전이 수·추출 파이프라인을 고정하고 **프로토콜만** 교체한 대조이므로,
개선분은 모델 자유도 증가가 아니라 **데이터 쪽 완화(hold) 효과**로 귀속된다.

**[해석]** `p-ocv` 잔차의 상당 부분은 **모델 결함이 아니라 데이터의 비평형 잔여**(완화 미완)다.
→ **권고**: 흑연 평형 형상(peak 폭·중심) 검증에는 `p-ocvhold` 를 쓴다.

**[supersede 대상]**
1. `comp_v24/DATA_REGISTRY.md` — §5b "★모델 문제 vs 데이터 문제 판정" 표의
   "clean 고밀도 실측 | SINTEF 흑연 | 63/mV | 0.95 | 잔차 원인 = **모델**(두-상 near-delta, MSMR 한계)" 행,
   및 같은 절 판정 문단의 "데이터가 깨끗하면(SINTEF·OCP) … **남는 잔차는 모델**" 단정.
   → **부분 supersede**: 깨끗한 고밀도 데이터에서도 잔차는 (모델 몫) + (**비평형 데이터 몫**)의 합이며,
   흑연에서 후자가 상당하다(R² 0.9770 → 0.9945). "데이터 품질"을 밀도·단조율로만 잰 축이 **프로토콜(완화) 축**을
   놓치고 있었다.
2. `comp_v24/FIT_CHECK_v1024.md` — §"정직한 한계" 의 "흑연 2→1 near-delta(≈0.09 V) 정점은 약간 underfit —
   MSMR 유한폭이 델타를 못 내는 구조 한계(… **데이터 아님**)" 의 "데이터 아님" 단정.

**[잔존 유효]** MSMR 유한폭이 진짜 델타를 재현할 수 없다는 **구조적 사실 자체는 유효**하다. A2 는 그 몫의
**크기를 줄일 뿐** 존재를 부정하지 않는다(hold 에서도 R² = 0.9945 < 1).

## A4. @3(regsol) 채택 근거 **철회** + 코드 **삭제**

**[사실]**
- v1.0.24 는 `comp_v24/ablation_result.json` 의 OFAT ablation 에서 @3 이득을 보고 채택했다.
  그 측정은 **전이 수가 낮게 고정된 조건**이었다.
- v1.0.25 재현(마스터 세션 측정):
  - 전이 수 **고정**(흑연 4 + Si 3) → @3 순효과 **+0.97 %p**
  - 전이 수 **승격**(흑연 7 + Si 7) → **−0.53 %p** — **부호 역전**
- 결론: @3 이득의 실체는 **전이 수 부족의 우회**였고 **gallery 세분과 중복**이다.
  → v1.0.25 에서 **코드 완전 삭제**: `_REGSOL_XG` · `_regsol_binodal_xa` · `_regsol_dqdv` ·
  `equilibrium()` 의 `'kernel'` 분기 제거. 커널 계통 = **로지스틱 단일계**.
- **단, Ω 파라미터 자체는 존치**한다. 삭제된 것은 **dQ/dV 커널**뿐이며, Ω 는 히스테리시스 gap ·
  ΔH_a^eff · §7 상성격 판정(Ω/RT ≷ 2)에 **계속 쓰인다**. 이 구분을 뭉개지 말 것.

동일 세션·동일 파이프라인 안에서 전이 수만 바꿔 나타났다는 사실**이다.

## A5. 배경 `C_bg` **비상수** 실측

**[사실]**

## A7. **gallery ≠ 상(phase)** — 판정 근거

> 물리 서술 본문은 마스터 소관(문건 §5b·§7·Ch3). 본 항은 **판정 근거 수치만** 등재한다.

**[사실]**
1. 7·9전이 피팅의 **중심 U** 는 기존 3개 피크 위치(**105 / 141 / 227 mV**)에 **ΔU < 12 mV 의 근축퇴(near-degenerate)
   쌍**으로 붙는다 → 늘어난 전이는 **새 위치의 상이 아니라 같은 봉우리의 형상 분해**다.
2. 흑연 **검출 피크 수**는 prominence 문턱을 낮추면 **3 → 4 → 5** 로 갈라진다 → "검출 피크 수" 는
   **문턱·해상도의 함수**이며 상 수의 측정치가 아니다.
3. 실리콘 **0.43–0.46 V feature** 는 `p-ocvhold` 프로토콜에만 있고 `p-ocv` 에는 **없다**
   (c-Li₁₅Si₄ 결정화 쌍) → feature 유무 자체가 **프로토콜 의존**이다.
4. **XRD 상 수는 불변**: Dahn, *Phys. Rev. B* **44**, 9170 (1991) in-situ XRD — 흑연 staging 전이 **4개**,
   물리 두-상은 **2L→2 · 2→1 둘**.

**[근거]** 1–3 = 마스터 세션 측정. 4 = 문헌(Dahn 1991) — `comp_v24/GRAPHITE_STAGING_XRD.md` §1 이 이미 등재한
정본 서지와 동일 논문.

**[supersede 대상]**
1. `comp_v24/GRAPHITE_STAGING_XRD.md` — §2 마지막 줄 "0.14–0.22 V 경사에서 별도 5번째 '상'을 뽑는 건 고용체
   shoulder 를 curve-fitting 하는 것(XRD 미지원). **6+ = 끼워맞추기**" 및 §5 항 1 "**전이 개수는 4개가 XRD 정당**.
   6개는 물리 위반(curve-fitting) — **폐기**".
   → **조준 정정(supersede)**: 그 금지는 **상(phase) 수**에 대해서는 그대로 유효하지만, **곡선 표현 해상도(gallery)**
   에는 적용되지 않는다. 7·9전이는 **상을 늘린 것이 아니라**(위 사실 1 — 기존 3위치에 ΔU<12 mV 로 축퇴) 같은 상의
   형상을 분해한 것이므로 "물리 위반"이 아니다. **상 수 = XRD 위임(불변)** / **전이 수 = 표현 해상도**로 두 축을
   분리해 읽어야 한다.
2. `docs/v1.0.25/results/REFLECT_SEED_TABLE.md` — §2 마지막 "**경계**: XRD 5-feature가 상한(Dahn).
   **6+ = curve-fitting(폐기 유지)**" 행. → 같은 이유로 supersede(상한은 **상 수**의 상한이며 전이 수의 상한이 아니다).
3. `comp_v24/DATA_REGISTRY.md` — §4 "조건별 파라미터 분포" 표(흑연 스테이징 피크 **3개** 행: 2→1 / 3→2L / 4→3).
   → **부분 supersede**: 3개는 그 문턱·그 창에서의 **검출 결과**이며(위 사실 2 — 문턱 완화 시 3→4→5),
   재료의 피크 수가 3 이라는 뜻이 아니다.
