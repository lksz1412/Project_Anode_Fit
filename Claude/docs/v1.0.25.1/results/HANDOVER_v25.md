### 1.4 핵심 결과 (정직)

- **@2 skew-logistic(C1)** — 전이 dict `alpha` 키(부재 = 1.0 = 현행 bit-exact). $\dd Q/\dd V=Q(\alpha/w)\xi_\eq^{\alpha}(1-\xi_\eq)$ 꼴,
  면적은 α 무관 보존. ★**정직**: α 는 **현상학적 형상 파라미터**(tier C)이고 새 물리·새 상이 아니다.
  또 **순수 비대칭 손잡이도 아니다** — 반높이 폭이 α=0.5/1/2/4 에서 4.45/3.53/3.02/2.74 w 로 함께 좁아져
  $w_j$($n_j$)와 축퇴하고, 정점이 전이 중심에서 $\sigma_dw_j\ln\alpha_j$ 만큼 밀린다(α=2 → **+17.8 mV**)
  → "정점 = 중심 $U_j^{\,d}$" 는 **α=1 한정**. 이것이 §18 4-손잡이 식별 가드의 근거다.
- **인과 pad(C2)** — `eq:lag` 의 하한 $-\infty$ 를 실현. 게이트 실측: 같은 물리점 세 시작점 상대산포
  **74.31% → 2.17e-04(0.02%)**. pad 길이의 커널 잔여 $e^{-5}\approx0.674\%$ 가 잔차 하한을 준다.
  ★ratio 경로에도 **같은** pad 를 넣어야 동결 극한 정확 회수가 유지된다(한쪽만 pad 하면 자기일관 게이트가 깨짐).
- **상수 SI(C3)** — opt-in. 문건 표시 25.693 mV = CODATA-2018, 구현 기본(레거시) 25.6912 mV.
  ★즉시 교체는 **골든 bit-exact 계약과 양립 불가**라 opt-in 으로 집행했다. SI 발효 시 회귀 기준은
  표시 자리까지 불변이고 **`U_oc(x̄=0.25)` 만** `.1f` 표시가 74.4→74.3 으로 뒤집힌다(raw 74.3511→74.3497,
  −1.42 µV — 74.35 반올림 절벽 인공물) → **정합 판정은 raw 값으로**.
- **regsol 삭제(C6)** — 커널 계통 = **로지스틱 단일계**. 근거는 물리 오류가 아니라 **실측 역전**:
  전이 수 고정(흑연4+Si3) +0.97 %p → 전이 수 승격(흑연7+Si7) **−0.53 %p**. 이득의 실체가
  "전이 수 부족의 우회" 였고 gallery 세분과 중복이다. ★**Ω 파라미터는 전량 존치**(히스 gap ·
  $\Delta H_a^\eff$ · §7 상성격 판정) — 삭제된 것은 dQ/dV **커널**뿐. 문건의 `eq:sifr-kernel`·`eq:sifr-blend`
  **식·라벨·boxed 는 보존**하고 지위만 "해석적 기록 — 미채택·코드 미구현" 으로 적었다.
- **$w_\eff$ 정정(C5)** — 중심 **높이** $Q/(4w_\eff)$ 는 모든 λ 에서 정확한 항등이지만
  $w_\eff$ 를 **폭으로 읽으면 안 된다**($\approx0.66/\sqrt\lambda$ 배 과대 — λ=10⁻²/10⁻³/5×10⁻⁴ 에서 6.6/21/30배).
  FWHM 닫힌형을 `eq:gr2l-fwhm` 로 신설(점근 $(16/3)(RT/F)\lambda^{3/2}$, 과대율 실측 λ=0.01:0.6% · 0.02:1.2% ·
  0.05:3.0% · 0.5:27% → **λ≳0.02 에서는 닫힌형을 쓴다**). 또 $\Omega=2RT$ 를 넘는 순간 평형 등온선은
  Maxwell 공존평탄으로 **불연속** 전환이라 "연속 보간이 아니다".
- **gallery ≠ 상(C7·A7)** — 7·9전이의 중심 U 는 기존 3위치(105/141/227 mV)에 ΔU<12 mV 근축퇴로 붙고,
  검출 피크 수는 prominence 문턱 따라 3→4→5, Si 0.43–0.46 V feature 는 `p-ocvhold` 전용.
  **XRD 상 수는 불변** — 사다리를 올려도 상은 늘지 않는다. **봉우리 수를 상 수의 증거로 제시하지 말 것**.
- **데이터 정직화(C9)** — 레포 `gr.csv` = gr_A = **`p-ocv`** / `si.csv` = si_Dhold = **`p-ocvhold`**(프로토콜 혼용).
  같은 7전이로 `p-ocv` 0.9770 → `p-ocvhold` **0.9945**(피크역 RMSE 4.708→2.701) → 잔차의 상당분이
  모델 결함이 아니라 **데이터의 비평형 잔여**. comp_v24 원본은 **무수정**이고 addendum 이 supersede 한다.
- **배경(C8·A5)** — dQ/dV 배경이 0.3–0.9 V 에서 0.433 → 0.032 단조 감쇠(창 평균의 ~230%, 4셀·2프로토콜 일치
  → 잡음 아님). 단 광폭 종 **단독 대체는 악화**(0.97702 → 0.97415)이고 **skew 동반 시에만 이득**(0.98178).
