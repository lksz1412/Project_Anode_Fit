  으로 접어 near-delta 를 세운 뒤 유한 폭 δ=w_j 로 broadening 을 얹는다".
  그리고 그 문단 끝: *"현재 구현에는 대응 경로가 **없다** … (v) 는 **재구현 시의 명세**로 읽되 현행 코드
  거동으로 읽지 말 것."*

**곧 흑연이 필요로 하는 Ω>2RT 두-상 regsol dQ/dV 는 문건에 식이 아예 없다.**
이론은 regsol 인데 수식이 단일상 가지밖에 없으니, 피팅이 로지스틱으로 가는 것은 구조적 귀결이다.

#### A-2. ★Ω>2RT 두-상 regsol dQ/dV 의 닫힌형 (본 인계의 핵심 자산)

v26 `regsol_kernel.py` 가 §(v) 가 요청한 "재구현 시의 명세" 를 **실제 식으로 닫았다**:

```
dQ/dV = Q · [ (1 − 2x_a) · κ(V − U₀; w)  +  ∫ ρ_ss(V′) · κ(V − V′; w) dV′ ]
```

- `x_a` = 대칭 정칙용액 binodal: `ln(x/(1−x)) + a(1−2x) = 0`, `a = Ω/RT`; `a ≤ 2` 면 `x_a = 1/2`(갭 없음)
- **1항 = 혼화갭**: 무게 `1 − 2x_a`, U₀ 에 선 near-delta 를 broadening 커널 κ 로 편 **닫힌형**. 조성격자 무관·정확.
- **2항 = 갭 밖 두 고용체 가지**: 조성 밀도 ρ_ss 를 전압축에 쌓고 κ 와 **합성곱** 1회.
  κ 가 (V−U) 만의 함수(**병진불변**)이므로 이 분해는 **근사가 아니라 항등**이다.
- 고용체 가지 전위: `U(x) = U₀ − (RT/F)·ln[x/(1−x)] − (Ω/F)(1−2x)` (= 문건 `eq:sifr-V` 와 동형)
- κ = 평형 미분 종. α=1 → 로지스틱 미분 `σ(1−σ)/w`, α≠1 → v1.0.25 skew `(α/w)σ^α(1−σ)` (∫κ dV = 1)

**[중요]** 로지스틱이 피팅에서 이기든 말든 **이건 이론 장(Ch2 §5 mixing · Ch3 §3.2b)의 자산**이다.

### C. 물리 — "이론은 regsol" 판단을 실제로 떠받치는 것

**C-1. 흑연 Ω 의 marginal 두-상 정합.** 흑연 4전이 Ω/RT = **2.54 / 2.03 / 1.88 / 2.30** — 전부 2RT 근방.
§5b 판정자(`eq:gr2l-disc`, Ω≷2RT)의 **첫 실측 대응**이며 "흑연은 두-상이되 **marginal**" 이라는 정량 진술이 가능해진다.
**적합도로는 졌지만 Ω 값 자체는 물리를 말한다** — "흑연이 두-상이다"(참)와 "그래서 regsol 커널이 gallery 를
대체한다"(거짓)는 **분리해서 읽어야 한다**. 이 분리가 사용자 결정(이론 regsol / 피팅 로지스틱)의 논리 근거다.

**C-2. 흑연 0.104 V 피크의 계측 한계 — 사용자 직관의 정량 근거.**
원자료에서 이 평탄은 V 폭 약 **0.6 mV 안에 2,400점 · 0.29 mAh** 가 몰려 **FWHM ≲ 1 mV = RT/F(25.7 mV)의 1/25**.
대칭 로지스틱이 맞추려면 w 를 **0.4 mV** 까지 내려야 하는데 **고용체로는 나올 수 없는 폭**이다. 두-상이면 자연스럽다.
→ **단, 비평형 인공물 가능성이 배제되지 않았다**(평형 데이터로만 갈린다). 반드시 이 단서와 함께 쓸 것.
- **[대상]** `ch1_sec05b_gr2L.tex` · `ch1_sec07_broadening.tex`

**C-3. regsol 도 분화를 겪는다 — A7 강화(커널 독립성).**
v25 A7 은 "gallery ≠ 상" 을 로지스틱에서만 보였다. v26 은 **regsol 을 N=4→7 로 올리면 BIC 2609.6→1825.3,
근축퇴쌍 1→4** 로 똑같이 늘어남을 보였다(근축퇴 정의 = |ΔU| < 5 mV 인데 폭비 > 2 인 쌍).
곧 "봉우리 세분 = 표현 해상도" 가 로지스틱의 성질이 아니라 **커널 독립 사실**로 격상된다 — A7 논지가 강해진다.
동시에 **검출 피크는 3개 그대로**인데 logistic 근축퇴쌍이 N=4→7 에서 **1→6** 으로 증가.
- **[대상]** `V1025_DATA_ADDENDUM.md` A7 보강 추기

**C-4. 소재별 커널 문헌 정리 + 신규 서지(선택 · 별건 phase 권장).**
Si = 연속 고용체(Chevrier-Dahn2009 · Artrith2018 · Papadopoulos2026, 유일 두-상 = c-Li₁₅Si₄) /
블렌드 = 중첩(Tu2024 · Kirkaldy2022 · Berhaut2023) / **Fujimoto2022 (C/250) = 9 피크 → "4전이" 는 coarse-graining**.
마지막 항은 v25 미해결 **M4**("흑연 물리 두-상 = 4 vs 2" 표기 불일치) 해소의 실마리.
- **[출처]** `comp_v26_data/MULTI_DATASET_REVIEW.md` §2·§3
