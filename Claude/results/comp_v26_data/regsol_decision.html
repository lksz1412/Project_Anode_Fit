Project Anode_Fit · regsol 반영 결정

regsol 적용 실측 피팅 결과 — 소재별 커널 결정

SINTEF 공개 실측(Zenodo 20086298, 반쪽셀) · dQ/dV = BDD 99_Backend 방식 · 마스터 세션 계산분

원래 지시(과제) — v1.0.25에서 삭제한 regsol을 되살릴지 결정하기 위해, v1.0.24 regsol 식 + v1.0.25 추가분을 제대로 된 공개 데이터(흑연·Si·흑연+Si 블렌드 3종)에 피팅해 이미지로 제시 → 당신이 보고 반영 여부 결정. dQ/dV는 BDD 99_Backend 방식, 데이터 품질 다각 검토 포함.

1. 흑연 — 실측 dQ/dV 피팅 (2셀)

셀피팅 R²주 피크 (V / mAh·V⁻¹)비고

우측 진단: shipped default(폭 w=RT/F)는 너무 넓어 실측 날카로운 피크를 전혀 못 따라감 → 폭을 좁혀야 맞음(두-상 sharpening 확정). 단 피크는 sharp하되 유한폭이라 좁은 logistic으로 R²≈0.95 확보.

2. 블렌드 — @1~@5 개선효과 ablation (실측 sigr, 기본 R²=0.987)

막대 = 문건기본(logistic) 대비 ΔR²(%p). 초록=실효 · 회색=무의미/해로움. Si 고용체(@3)만 유일한 실효(+0.67%p)이고, 흑연 regsol near-delta(@1)는 오히려 −0.02%p.

3. 결론 — 소재별로 커널이 갈린다 (실측 근거)

소재물리맞는 커널실측 판정
실리콘연속 고용체(단일상)Frumkin regsol Ω<2RT+0.67%p 실효 → regsol 가치 확인
흑연두-상(sharp, 유한폭)좁은 logistic (또는 regsol+유한δ)R²≈0.95 이미 충분
흑연(near-delta)무한 sharp 가정regsol Ω≫2RT near-delta−0.02%p → 과함(오버슈트)
블렌드중첩흑연 logistic + Si Frumkin@3만 추가로 실효

반영 권고 — "regsol을 통으로 되살리자"가 아니라 소재별로:

✅ Si = regsol(Frumkin Ω<2RT 고용체) 되살릴 가치 있음 — 실측서 유일하게 +0.67%p 개선.

⚠ 흑연 = near-delta regsol은 불필요(−0.02%p, 오버슈트). 좁은 logistic으로 이미 R²0.95. 두-상 물리를 넣으려면 regsol+유한 δ(kinetic 폭) 형태여야 하며 그때도 logistic 대비 이득 실증 필요.

※ 위는 plain p-OCV(비평형) 데이터 기준. GITT/hold 평형 데이터로 재검하면 흑연 피크가 더 날카로워져 결론이 강화될 가능성 있음(코드 게이트 복구 후 실행 예정).
